# Installation

## Code Generator

For quick usage, we recommend using the code generator approach. As mentioned earlier, ForensicHub consists of four modular components, allowing you to:
- Quickly implement your own dataset loader or data augmentation methods
- Try replacing different model backbones or feature extractors
- Choose evaluation metrics suitable for various tasks
- Construct a brand-new pipeline by combining components

## In-depth Development

For in-depth development, we recommend cloning the project to your local environment, which enables you to deeply develop according to your requirements, such as:
- Modifying the specific implementation of existing components (e.g., model structure, data loading logic, evaluation metrics, etc.)
- Adding new models or task types to expand the current range of supported functionalities
- Adjusting the core execution process, such as adding new training protocols or experimental control logic
- Seamlessly integrating with existing scientific research projects as a foundational library or analysis tool
This mode is highly suitable for exploratory experiments and deep customization development in scientific research scenarios.

💡 Whether for quick trials or in-depth development, ForensicHub supports you in building complex, multi-task, cross-domain image forensics research Pipelines at the lowest cost.
